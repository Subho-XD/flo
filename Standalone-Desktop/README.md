# Flo Desktop
### A standalone screen recorder for Windows

Flo Desktop is a native Windows screen recorder designed to make capturing your desktop, applications, games and creative workflows straightforward. Configure your recording, capture what you need, and manage your saved videos in one application.

## Installation

**Download the official installer:** `Flo-Desktop-Setup.exe`

1. Open the [Flo GitHub Releases page](https://github.com/Subho-XD/flo/releases).
2. Find the release labelled **Flo Desktop** with a tag beginning `desktop-`.
3. Download `Flo-Desktop-Setup.exe` from that release.
4. Run the installer.
5. Read and accept the End User License Agreement.
6. Follow the installation steps.
7. Launch Flo Desktop from the Windows Start menu.

You do not need Adobe Photoshop, InDesign or any other Adobe application to use Flo Desktop.

Only download the installer from the official Flo GitHub repository or the official Flo website. Do not use unofficial mirrors or redistributed copies.

## Uninstallation

To uninstall Flo Desktop:

1. Open **Windows Settings → Apps → Installed Apps**.
2. Find **Flo Desktop**.
3. Open its options and select **Uninstall**.
4. Follow the uninstaller instructions.

Your saved recordings and personal files are preserved by default. Removing Flo Desktop does not automatically remove your recording library. You can delete those files separately when you no longer need them.

## Getting Started

1. Launch Flo Desktop.
2. Choose what you want to capture.
3. Configure your recording mode, codec, audio and output settings.
4. Select your save location.
5. Click **Start Recording**.

During a recording, use the floating Flo control bar to pause, resume or stop the session. Your completed recordings appear in the **Recordings** section.

## Capture Options

Flo Desktop supports different ways to capture your screen:

- **Monitor:** Record an individual display or combine multiple displays into one recording.
- **Separate Recordings:** Capture multiple displays simultaneously as independent video files, organised in a session folder.
- **Applications & Games:** Select an application or game to capture.
- **Custom Region:** Select a specific rectangular area of your desktop.

## Recording Options

- **Normal Video:** Capture your screen in real time.
- **Live Time-Lapse:** Capture frames at configurable intervals to create accelerated workflow videos.
- **H.264 and HEVC:** Choose an available video codec according to your system's encoder capabilities.
- **Audio Capture:** Configure system audio and microphone input independently.
- **Output Controls:** Configure supported video profiles, keyframe intervals, colour settings, audio bitrate, naming patterns and storage location.

Hardware acceleration and available encoding options depend on your graphics hardware, drivers and Windows configuration.

## Managing Recordings

The built-in Recordings library helps you manage your saved videos.

You can browse recordings, view their details, play them, open their containing folders and organise your files.

Multi-display recording sessions are grouped so that their independent video files are easy to locate.

## System Requirements

- Windows 10 or Windows 11, 64-bit.
- A compatible graphics adapter and up-to-date drivers.
- Supported Windows Graphics Capture and Media Foundation components.
- Sufficient available storage for your recordings.

Hardware encoding availability varies by GPU, driver and selected codec. Flo displays the encoding options available on the current system.

**Windows N editions:** The Windows Media Feature Pack may be required for relevant media and encoding components.

## Updates

Flo Desktop includes a built-in **Check for Updates** option.

Open **About → Check for Updates** to see whether a newer version is available. Flo checks the official GitHub repository for the latest compatible Desktop release. When an update is available, the application provides access to its official installer.

Updates are downloaded through the official release link and remain under your control.

## Privacy and Storage

Your recordings are saved locally to the storage location you choose.

Flo Desktop does not collect analytics or telemetry, require an account, or upload your screen recordings, audio, documents or other personal content to the Publisher.

The Check for Updates feature connects to GitHub over HTTPS to retrieve public release information. GitHub may process ordinary connection and request metadata according to its own policies. Your recordings and captured content are not included in that request.
