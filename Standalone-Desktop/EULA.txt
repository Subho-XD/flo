### Update Checking

The Application includes a Check for Updates feature.

When you initiate an update check, Flo Desktop connects to the public GitHub releases API over HTTPS to retrieve release information for compatible Flo Desktop versions.

The update checker uses this information to identify a newer Desktop release and its official installer download address.

GitHub may process standard connection and request metadata under its own terms and privacy policies.

The update-check request does not include your recordings, captured screen content, documents or audio.

When an update is available, Flo Desktop provides access to its official installer. The user controls whether to download and install it. The update checker does not silently install an update.
